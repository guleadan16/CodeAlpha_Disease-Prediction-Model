# Disease Prediction Using Machine Learning

## Project Description

This project predicts whether a patient has heart disease using machine learning algorithms. The model is trained on a heart disease dataset and can predict the disease based on patient health information.

## Features

* Heart disease prediction
* Data preprocessing and scaling
* Trained machine learning model
* Prediction using saved model and scaler

## Files Included

* `disease prediction.ipynb` – Model training notebook
* `predict model.ipynb` – Prediction notebook
* `heart(1).csv` – Dataset
* `heart_disease_model.pkl` – Trained model
* `scaler.pkl` – Saved scaler

## Technologies Used

* Python
* Pandas
* NumPy
* Scikit-learn
* Matplotlib
