# 🫀 Disease Prediction Using Machine Learning

## 📌 Project Overview
This project is a machine learning-based disease prediction system developed as part of the **CodeAlpha Machine Learning Internship**. The model predicts whether a patient is likely to have heart disease based on various medical parameters.

## 🎯 Objective
The objective of this project is to build an accurate disease prediction model using machine learning algorithms and provide predictions based on patient health data.

## ✨ Features
- Data preprocessing and cleaning
- Feature scaling using StandardScaler
- Model training and evaluation
- Disease prediction using a trained machine learning model
- Save and load trained model using Pickle

## 🛠️ Technologies Used
- Python
- Jupyter Notebook
- Pandas
- NumPy
- Scikit-learn
- Matplotlib
- Pickle

## 📂 Project Files
- `disease prediction.ipynb` – Model training notebook
- `predict model.ipynb` – Prediction notebook
- `heart.csv` *(or `heart(1).csv` if you haven't renamed it yet)* – Dataset
- `heart_disease_model.pkl` – Trained machine learning model
- `scaler.pkl` – Saved feature scaler

## 🚀 How to Run
1. Clone this repository.
2. Install the required Python libraries.
3. Open the notebooks in Jupyter Notebook or Google Colab.
4. Run `disease prediction.ipynb` to train the model.
5. Run `predict model.ipynb` to make predictions using the saved model.

## 📊 Dataset
The project uses a Heart Disease dataset containing patient health attributes for disease prediction.
